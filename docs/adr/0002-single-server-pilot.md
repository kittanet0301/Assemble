# ใช้เซิร์ฟเวอร์เดียวสำหรับกลุ่มทดลอง

กลุ่มทดลองมีเพดานสมาชิก 50 คน ออนไลน์พร้อมกัน 20 คน และห้องประชุมละ 8 คน จึงเริ่มด้วย Node.js server เดียวที่ตัดสินตำแหน่ง การชน สิทธิ์ และจำนวนผู้เข้าห้อง เก็บข้อมูลถาวรใน SQLite และใช้ WebSocket สำหรับ presence เพื่อให้ทดลองในเครื่องและย้ายไปเซิร์ฟเวอร์องค์กรได้โดยไม่ต้องตั้งฐานข้อมูลหรือ message broker แยก; ข้อแลกเปลี่ยนคือยังไม่รองรับการกระจาย presence หลาย replica และต้องออกแบบส่วนนี้ใหม่เมื่อขยายขนาด

สื่อประชุมแยกผ่าน LiveKit และตัวตนบริษัทผ่าน OIDC; ทั้งสองส่วนต้องตั้งค่าและทดสอบกับบริการจริงก่อนเปิด pilot เซิร์ฟเวอร์ตรวจสิทธิ์ก่อนออก media token โดย client ไม่ถือกุญแจบริการ
