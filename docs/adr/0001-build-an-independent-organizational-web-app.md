# สร้างเว็บอิสระสำหรับใช้ในองค์กร

หลังประเมิน FinGW บน ZEP และเปรียบเทียบการสร้างบน ZEP กับการสร้างเว็บอิสระ ผู้ใช้เลือกสร้างเว็บของเราเองสำหรับใช้ในองค์กรเมื่อ 18 ตุลาคม 2026 การเลือกนี้ทำให้ระบบต้องมีความสามารถด้านแผนที่ ผู้เล่นหลายคน และการสื่อสารตามขอบเขตที่จะตกลงกันต่อ แทนการพึ่งระบบเหล่านี้ของ ZEP; ยังไม่ได้ตัดสินใจเรื่องเทคโนโลยี ผู้ให้บริการ จำนวนผู้ใช้ หรือฟีเจอร์เวอร์ชันแรก
